# Записанные решения

| Решение | Почему | Цена и ограничение |
|---|---|---|
| Физический граф вместо геометрического merge | Пересекающиеся трассы могут принадлежать разным системам | Ошибочные соединения в RVT нужно исправить в модели |
| Виртуальные узлы на прямых сегментах | Точная длина между промежуточными подключениями без изменения лотков | Кривые требуют отдельной параметризации; пока только коннекторы |
| Одно дерево Дейкстры | Все устройства связаны с одним выбранным контроллером | Назначение нескольких контроллеров — отдельная задача оптимизации |
| BVH над сегментами и точками | Ускорить nearest query без зависимостей от Revit/геометрических библиотек | Worst case линейный; индекс строится для каждого снимка |
| Predecessor хранит ребро | Параллельные рёбра могут иметь разную длину/геометрию | Больше памяти, чем только previous node |
| Порты и constructor DI | Проверить сценарий calculate–model change–save без хоста | DTO и синхронный контракт; не распределённая consistency model |
| Presentation отдельно от WPF | Ввод, команды, локализация и фильтр проверяются на Linux | Дополнительная небольшая сборка в поставке |
| Модальные окна | Простой корректный API-контекст и жизненный цикл документа | Нет фонового host-расчёта и modeless взаимодействия |
| Снимок fingerprint вместо отметки времени | Точечные геометрические изменения и настройки должны инвалидировать данные | Перечитывание модели перед записью; hash не подписывает результат |
| JSON version отдельно от Revit Schema | Schema неизменяема, формат продукта развивается | Миграции обязательны; неизвестная версия запрещает запись |
| GUID и явный scope параметра | Не угадывать среди локализованных/одноимённых параметров | Требуется контракт проектировщика/производителя |
| Диапазоны только Integer | Не считать feet/volts/счётчики одной и той же величиной | Для Double нужен отдельный units-aware контракт |
| Только пустые марки исправляются автоматически | Существующие марки могут быть внешними ссылками | Дубликаты требуют решения пользователя |
| Ownership tags для схем | Регенерация не должна удалять пользовательские аннотации | Чужие зависимости блокируют замену, старые страницы сохраняются |
| Standalone SVG/HTML отчёт | Просмотр результата на Linux и без Revit/сети | Проекции 2D; это снимок, а не live editor |
| Минимальный deployment через .addin | Проверяемая пользовательская установка без admin | MSI, подпись и обфускация пока отсутствуют |

Для промышленного расширения сначала получить эталонные RVT/семейства, GUID/единицы параметров, правила подводок и ограничений оборудования. Затем добавить units-aware Double правила, linked models с трансформациями и параметризацию кривых. Добавлять технологии без этих контрактов не повышает достоверность расчёта.
