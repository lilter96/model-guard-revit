# Первый запуск без знания Revit

Revit — BIM-программа: вместо картинки здания хранит модель из объектов. Дверь — экземпляр семейства, её размер/конструкция — типоразмер, марка и прочие данные — параметры. Revit API позволяет читать и менять эти объекты. Изменения выполняют в транзакции.

На Linux можно читать код, запускать тесты и расчётное демо. Сам Revit и WPF-интерфейс требуют Windows. Для первого рабочего прогона достаточно одной версии: удобно Revit 2025, соответствующий установленным API/.NET 8. Используй законно доступную лицензию или тестовый доступ Autodesk; доступность и условия проверяй у Autodesk.

## Подготовка модели

1. Открыть небольшой **проект**, а не редактор семейства.
2. Разместить несколько кабельных лотков и фитингов с физически соединёнными коннекторами. Визуально соприкасающиеся элементы не обязательно соединены.
3. Разместить три семейства оборудования с точкой размещения: одно будет контроллером, два — устройствами. Эти роли задаёт выбор пользователя; никаких специальных Sigur-семейств не требуется.
4. Расположить точки устройств и контроллера в пределах 3 м от прямых сегментов лотков или их коннекторов. Прямые сегменты допускают подключение к середине.
5. Для ModelGuard использовать двери и оборудование категорий Electrical Equipment, Electrical Fixtures, Data Devices, Communication Devices, Specialty Equipment; Security Devices и Fire Alarm Devices включаются, если присутствуют в API данного выпуска. Марка — стандартный параметр экземпляра; имена в интерфейсе Revit зависят от языка.

## AccessRoute

1. Выделить экземпляры устройств, **без контроллера**, до запуска команды.
2. На вкладке Надстройки нажать «Кабельные маршруты».
3. Выбрать контроллер в модели; Esc отменяет выбор.
4. Указать максимум подводки, запас, припуск и предел длины (0 отключает предел).
5. В таблице посмотреть статус и итоговую длину каждого кабеля.
6. «Показать выбранный элемент» закрывает отчёт, выбирает элемент в модели и вновь открывает отчёт; элемент выделяется, но окно может перекрывать вид. Закрыть отчёт, чтобы осмотреть модель.
7. «Экспорт CSV» сохраняет таблицу. «Сохранить расчёт в модели» сохраняет JSON в DataStorage; затем сохранить сам RVT обычной командой Revit.
8. После изменения геометрии выполнить новый расчёт: сохранённые результаты автоматически не обновляются. При следующем запуске сохранённые настройки подставляются в диалог.

## ModelGuard

1. Нажать «Проверить модель». Поле обязательных параметров можно оставить пустым либо ввести, например, `ACS_System;ACS_Controller`.
2. Посмотреть замечания. Дубликаты марок сравниваются без регистра и крайних пробелов по всей области проверки.
3. Для отсутствующего параметра одинаково отмечаются отсутствие, пустое значение и несколько одноимённых параметров. Это сознательно строгая проверка.
4. Нажать «Предпросмотр заполнения марок». В отдельной таблице появятся точные будущие марки.
5. Нажать «Применить изменения из списка» либо закрыть окно. Заполненные и недоступные марки не меняются.
6. Отчёт перечитывает модель после применения. Undo отменяет транзакцию.

## Если что-то не работает

- Панелей нет: проверить год манифеста, абсолютный путь DLL в `.addin`, затем перезапустить Revit. Подробности в журнале Revit.
- Команда просит выбрать устройства: нужен заранее выделенный экземпляр семейства с точкой размещения, не тип/стена/лоток/связь.
- Все маршруты слишком далеко: приблизить устройства к прямому сегменту или коннектору, либо увеличить предел, понимая, что это разрешает длинную прямую подводку.
- «Разрыв сети»: проверить реальные соединения лотков/фитингов.
- Ошибка записи: проверить read-only, доступность элементов в worksharing и журнал. При ошибке транзакция не должна оставлять частичных изменений; это необходимо подтвердить сценарием приёмки.
- Неизвестная версия данных: не удалять данные для обхода ошибки. Скопировать модель и подготовить миграцию.

## Новые действия AccessRoute

- «Выделить маршрут в модели» — выбирает элементы трассы, устройство и контроллер. Это выделение объектов, а не создание физической модели кабеля.
- «Интерактивный отчёт» — сохраняет автономный HTML. Открыть в браузере, выбрать устройство и переключить XY/XZ/YZ.
- «Создать схему подключений» — создаёт страницы ViewDrafting с логическими соединениями и длинами, до 18 устройств на страницу. После Commit Revit получает запрос открыть первую страницу. Повторный запуск обновляет собственные аннотации; человеческие сохраняются. Если пользовательский размер зависит от генерируемой линии, обновление блокируется.
- При изменённом или непроверяемом старом расчёте отображается замечание. Сохранение нового плана требует совпадения входного снимка с моделью.

## Профиль ModelGuard

Можно выбрать `samples/acs-profile.json`. Он заменяет свободный список обязательных параметров. Это демонстрационный контракт; в своей модели нужно создать параметры либо адаптировать профиль. Имена категорий — значения BuiltInCategory, например OST_ElectricalEquipment. GUID должен быть реальным GUID вашего shared parameter, не случайным идентификатором из примера.

Scope Instance требует параметр на экземпляре; Type — на типе; InstanceOrType допускает fallback. Integer ranges применимы только к целочисленным параметрам. References проверяет значение параметра как марку оборудования заданной категории.
