# Проверка внутри Revit — ещё не выполнена

Не отмечать пункты как пройденные на основании компиляции. Для каждого выпуска 2021–2025 записать точный build Revit, Windows, runtime, используемый шаблон/семейства, результаты и доказательства (скриншот/видео/журнал). Модели создавать и сохранять отдельно для каждого выпуска: RVT из более нового Revit нельзя считать тестом старого.

## Доказательство для портфолио

Записать 2–3 минуты: модель, исходные ошибки, запуск, результаты, предпросмотр изменений, Undo, сохранение/повторное открытие. Показывать одну подтверждённую версию в ролике и указывать фактически проверенные версии в README. ## Дополнительная приёмка после усиления

| Проверка | Ожидание | Результат |
|---|---|---|
| Устройства рядом с серединой длинного прямого лотка | Подключение к проекции; ручная проверка длины подучастка | Не выполнена |
| Несколько точек на одном сегменте | Нет обхода через дальние коннекторы, нет дублей виртуальных точек | Не выполнена |
| Вертикальный прямой сегмент | Привязка и длины учитывают Z | Не выполнена |
| Кривой лоток | Верная длина графа, диагностика connector-only attachment | Не выполнена |
| Предел длины | CableLimitExceeded с сохранённым путём | Не выполнена |
| Выделить маршрут | Выбираются правильные элементы трассы + концевые устройства | Не выполнена |
| Генерация 43 устройств | Три drafting-страницы, все устройства представлены один раз | Не выполнена |
| Повторная генерация | Собственные линии/заметки заменены, страницы не дублируются | Не выполнена |
| Пользовательская заметка на странице | Сохранена после регенерации | Не выполнена |
| Пользовательский размер к генерируемой линии | Регенерация блокируется без частичного изменения | Не выполнена |
| Уменьшить число устройств | Лишние старые страницы отмечены, человеческие аннотации сохранены | Не выполнена |
| GUID shared parameter и одноимённый другой параметр | Выбран GUID, не случайный одноимённый параметр | Не выполнена |
| Instance rule, параметр только на типе | ParameterScopeMismatch | Не выполнена |
| Integer rule, Double значение | ParameterTypeMismatch | Не выполнена |
| Ссылка на отсутствующий/повторный контроллер | UnresolvedReference / AmbiguousReference | Не выполнена |
| Модель изменена после расчёта | Старый снимок не сохраняется как актуальный | Не выполнена |
| JSON v2 | Длины сохранены, актуальность Unknown; требуется пересчёт | Не выполнена |
| Поздний экспорт завершился ошибкой после успешного Save | Ранее сохранённый результат не откатывается всей командой | Не выполнена |

Для host-ошибок собрать JSONL журнал и journal Revit. Указанные сценарии проверены частично на уровне ядра/портов, но таблица относится только к фактическому исполнению в Revit.
